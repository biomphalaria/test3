## Excel Macro

`vba/TLEMacros.bas` に VBA コードを保存しています。以下の手順でマクロを使用できます。

1. Excel で新しいブックを作成し、Sheet1～Sheet5 を準備してください。
2. VBA エディタ (Alt+F11) を開き、`TLEMacros.bas` をインポートします。
3. Sheet1 に "TLEインポート" ボタンを配置し、`ImportTLE` マクロを割り当てます。
4. Sheet3 の 1 行目に "着目衛星抜き出し" ボタンを配置し、`ExtractFocusedSatellites` マクロを割り当てます。
5. Sheet5 に "TLEエクスポート" ボタンを配置し、`ExportTLE` マクロを割り当てます。

ファイル選択には `FileDialog` を使用していますが、コードでは遅延バインディング
を利用しているため特別な参照設定は不要です。

Sheet3 の A 列に名称、B 列に NORAD ID、C 列に COSPAR ID を入力すると、ボタン押下時に該当する TLE セットが Sheet5 に出力されます。

抽出処理では 名称・NORAD ID・COSPAR ID のいずれも大文字/小文字を無視した完全一致で比較します。入力値の前後に含まれる全角スペースやノーブレークスペースも自動的に取り除かれるため、貼り付けたデータに余分な空白があっても問題ありません。COSPAR ID は `2012-066A` のような形式だけでなく、`12066A` のような TLE 表記や `‑` `－` など異なるハイフン記号を用いた入力でも同じ ID として扱われます。TLE ファイル中に空行が含まれていても自動的にスキップされ、名称を空白のまま NORAD ID や COSPAR ID のみで抽出することも可能です。抽出されたデータは Sheet5 の "TLEエクスポート" ボタンからテキストとして保存できます。
